Metodologia

Como o SmokeDistance funciona

Três observadores, um resultado preciso. O app usa seus sensores embarcados para localizar incêndios com precisão geodésica.

01

Observação

O usuário aponta para a fumaça usando a câmera. O app captura azimute, inclinação, GPS e altitude via sensores do celular.

02

Triangulação

Com dois ou mais observadores em posições distintas, o sistema cruza as linhas de visada e calcula a localização exata do foco.

03

Confirmação

O usuário pressiona Travar Foco — o azimute é fixado e uma foto é capturada automaticamente. Em seguida pressiona Enviar ao Mapa e a linha de observação aparece no mapa de todos os usuários conectados em tempo real.

04

Alerta

A localização é compartilhada em tempo real com todos os usuários conectados e autoridades via notificação de emergência.

O Aplicativo

Cada tela, uma missão

Seis módulos integrados, cada um desenhado para uma etapa do ciclo de detecção e resposta.

🗺️

Mapa Tático

Visualização em tempo real dos focos marcados, linhas de observação de todos os usuários conectados, fontes d'água e pontos de risco. Bússola digital integrada mostra o azimute de cada observador.

Google Maps + Firebase Sync
📷

Câmera de Campo

Captura fotos geolocalizadas com azimute, altitude e inclinação embutidos nos metadados. Overlay de bússola e linha de visada sobreposta à imagem em tempo real.

GPS · Barômetro · Bússola
🛰️

Satélites

Integração com FIRMS (NASA), GOES-16 e MSG para confirmação independente de focos de calor. Focos ativos exibidos sobre o mapa com timestamp e intensidade radiativa.

FIRMS · GOES · MSG
🔥

Propagação

Modelo matemático Rothermel calcula a velocidade e direção de espalhamento do fogo baseado em vento, declividade, tipo de vegetação e umidade do combustível.

Modelo Rothermel ROS

Gera links de emergência e QR codes com a localização do foco, mapa de propagação e dados meteorológicos. Envio direto para WhatsApp, e-mail ou autoridades.

Galeria de fotos organizadas por pino no mapa. Cada registro contém imagem, hora, coordenadas, azimute e usuário que capturou — rastreabilidade total de campo.

Política de Privacidade

Última atualização: junho de 2026

1. Dados Coletados

O SmokeDistance coleta os seguintes dados para funcionamento do aplicativo:

  • Localização (GPS): usada exclusivamente para triangulação de focos e exibição no mapa. Não é armazenada permanentemente sem ação do usuário.
  • Fotos de campo: capturadas pelo usuário e armazenadas no Firebase Storage associadas a um pino de localização.
  • Dados de sensores: bússola, barômetro e giroscópio são usados localmente para cálculo de azimute e altitude — não são transmitidos.
  • Identificador de dispositivo: usado para sincronização colaborativa entre usuários da mesma sessão.

2. Como Usamos os Dados

Os dados coletados são utilizados exclusivamente para:

  • Triangulação geodésica colaborativa de focos de incêndio
  • Exibição de focos no mapa compartilhado entre usuários
  • Armazenamento de fotos de campo geolocalizadas
  • Envio de alertas de emergência entre usuários

3. Compartilhamento de Dados

O SmokeDistance não vende, não aluga e não comercializa dados de usuários. Os dados são compartilhados somente:

  • Com outros usuários do mesmo grupo de monitoramento
  • Com o Firebase (Google) para sincronização em tempo real
  • Com APIs de satélite (NASA FIRMS, NOAA) — apenas coordenadas são enviadas

4. Retenção de Dados

Fotos e focos marcados são retidos no Firebase enquanto o usuário não os remover. O usuário pode excluir seus dados a qualquer momento dentro do aplicativo.

5. Permissões do Aplicativo

  • Câmera: captura de fotos de campo
  • Localização (em uso): triangulação e exibição no mapa
  • Notificações: alertas de emergência
  • Rede: sincronização Firebase e dados de satélite

6. Segurança

Os dados são protegidos por autenticação Firebase e regras de segurança do Firestore. As comunicações são criptografadas via HTTPS/TLS.
